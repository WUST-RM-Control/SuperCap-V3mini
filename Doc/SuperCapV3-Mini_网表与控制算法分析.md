## 0. 结论摘要

1. **拓扑**：A 侧（裁判/底盘母线）↔ B 侧（超级电容组）之间的 **四开关非反相 Buck-Boost**，2 个半桥驱动 ±180° 交错，340 kHz，10 µH 单电感，4×BSC066N06NS。
2. **采样**：2 路电压（11:1 分压）+ 3 路电流（4 mΩ + INA240A1×20，双向、1.65 V 零点，满量程 ±20.6 A）。全部经片内 OPAMP 跟随器进 ADC，ADC 由 HRTIM 触发。**5 路里只用了 4 路做闭环，B 侧电流全程"白测"。**
3. **控制**：单回路——测裁判功率 `P_ref` → PI 得 `Target_A_P` → 再由另一个 PI 把 `P_A` 跟到 `Target_A_P`，输出一个"电压修正量 ΔV"，与电容电压相加后除以母线电压得变比 → 查表得两桥占空比。**没有电流内环、没有负载前馈。**
4. **发现的 6 个实质问题**（详见 §4）：
   - 两个"电容电压上下限"环是**对称积分器**，正常工况下必然饱和在允许方向，**实际不工作** → 上限只剩 27 V 硬保护，变成 26/27 V 的 bang-bang 振荡；
   - ~~能量环 `Max_Referee_P − PowerBuffer.Output` 的符号方向与物理相反~~ —— **此条已撤回，见 §4.2 更正**（旧符号在 RM 规则口径下是正确的）；
   - 无负载前馈，功率过冲只能靠积分追 → 正是裁判功率计要罚的部分；
   - PID 增益是"每拍"量且跑在**不定速主循环**里；OLED 阻塞刷新（≈7–8 ms）发生在 1 kHz 中断内，**同时卡住控制环和保护环**；
   - 过流保护被注释，且阈值 40 A **高于传感器满量程 20.6 A**，即使打开也永远不触发；
   - 硬件侧：CAN_RX 上挂 100 nF（1 Mbps 无法通信）**[需实测]**、PB8=BOOT0 被 OLED SCL 占用、VREF+(3.300 V) 可能高于 VDDA(3.3 V±2%)。
5. **改进方向**（§5）：改成 **电流环（20 kHz，均值采样）→ 功率环（1–2 kHz，带负载前馈）→ 能量环（10–100 Hz）** 的三层级联；把电压限幅从"积分器"改成"参考值域的乘性 taper"；控制与调度全部搬到固定频率中断。

## 1. 网表解码

### 1.1 功率主回路

```
      REFEREE+ (CN1: XT30-M, 底盘/裁判侧输入)          B_POWER_RI- (CN2/CN3: 2×XT30-M, 电容组)
         │  D9 SMCJ33A                                     │  D13 SMCJ33A
         │                                                 │
        R77 4mΩ ──► A_POWER_RI+ ──┬── U33 (XT30-F, 负载/UAV 侧)
         │  (U30 测 I_ref)         │
         │                        R6 4mΩ (U29 测 I_A)
         │                        │
         │                     A_POWER ──┬── C26 470µF ∥ 3×10µF
         │                               ├── Q11 D (HS)  ── A_SW ──┬── L2 10µH ──┬── B_SW ──┬── Q9 D (HS)
         │                               ├── R23/R24 11:1 → A_POWER_V_ADC        │          ├── B_POWER ── C6 470µF
         │                               └── D1 K34 ──┐                           │          │            └── R26/R27 11:1 → B_POWER_V_ADC
         │                                            │                     Q12 S(→GND)  Q10 S(→GND)
         │                                     $1N196 ┴── D2 K34 ◄── B_POWER
         │                                        │
         │                                      F1 0.5A 自恢复
         │                                        │
         └────────────────── aux: $1N18 → U1 RY8411 → L7 → "12V"(≈10.1 V, 栅驱) 
                                     → U2 RY8411 → L8 → 5V → LDO1 ME6211C33 → 3V3
                                                            → U3 REF3033 → 3V3REF (ADC VREF+ & INA240 REF2)
```

- **两桥 180° 交错**：TIMER_A 由 MASTER_CMP1（计数 0）复位，TIMER_B 由 MASTER_CMP3（计数 8000＝半周期）复位 → 输入/输出电流纹波对消一半。
- **"12V" 网名是历史遗留**：`R13=118k / R4=10k`，若 RY8411 基准 0.8 V 则输出 = 0.8×12.8 ≈ **10.1–10.2 V**（5 V 轨用 `R12=53.6k/R7=10k` → 0.786 V×6.36 ≈ 5.0 V 反推基准≈0.786 V）。这解释了栅极 TVS 全用 **SMF10A**（10 V 挡位）而不是 12 V 系列——内部自洽。**[需实测]**：若真想要 12 V，R13 应为 ≈140 k；现在 R13 上并联的 D4(SMF10A) 工作在挡位电压边缘。
- 栅极驱动非对称：开通走 `R3/R5/R1/R2 = 3.3 Ω`，关断经 `D7/D8/D10/D21 (1N4148W)` 旁路 → 关断快、开通慢。
- **死区只有 ≈1.5 ns**（HRTIM DT 预分频 DIV8 × 1 计数 × 184 ps）。真正的死区靠上述"关断快/开通慢"的驱动非对称性保证，不是设计保证，随温度/批次漂移。`A_Duty` 上限 0.95 是有意的：给 UCC27282 的 100 nF 自举电容留 ≈150 ns/周期 的刷新窗口。
- 辅助电源经 `D1/D2` 从 A、B 两侧"或"取电（0.5 A 保险丝）→ **电容侧有电时板子仍在线**，可以自己把自己放电/上报，这是刻意设计。

### 1.2 采样链（5 通道）

| 量 | 传感器 | 网络 | MCU | ADC/OPAMP | 换算 |
|---|---|---|---|---|---|
| `A_Power_V` | R23/R24 100k:10k | `A_POWER_V` → R105 22Ω ∥ C175 100n | PA3 (17) | ADC1 / OPAMP1 跟随 | ×11，满量程 36.3 V |
| `A_Power_I` | R6 4 mΩ + U29 INA240A1(×20) | `A_POWER_I_V` → R103 ∥ C173 100n | PA7 (21) | ADC2 / OPAMP2 | 12.5 A/V，1.65 V 零点 |
| `Referee_I` | R77 4 mΩ + U30 | `REFEREE_I_V` → R102 ∥ C172 | PB0 (24) | ADC3 / OPAMP3 | 同上 |
| `B_Power_I` | R79 4 mΩ + U31 | `B_POWER_I_V` → R104 ∥ C174 | PB13 (35) | ADC4 / OPAMP6 | 同上 |
| `B_Power_V` | R26/R27 100k:10k | `B_POWER_V` → R106 ∥ C176 | PB14 (36) | ADC5 / OPAMP5 | ×11 |

要点：

1. **两级串联分流电阻**：`REFEREE+ --R77--> A_POWER_RI+(负载抽头 U33) --R6--> A_POWER(变换器)`。因此
   `I_ref = I_load + I_A`，`P_load = P_ref − P_A` —— 固件里 `Chassis_P = Referee_P − A_Power_P` 正是这个关系，是对的。
   代价是主回路多了 **8 mΩ**（20 A 时 3.2 W、压降 160 mV）。
2. **DC 母线分流 + 470 µF 大电容**把脉动电流滤成近似直流，所以"单点瞬时采样"对这两路是成立的（A_POWER 上 C26=470 µF，阻抗在 340 kHz 约 1 mΩ）。这是设计上做对的地方。
3. **ADC 触发点**为 `CMP4 = 8000 + D×8000`，即低边导通窗口的中点（避开开关沿）。因 (2)，采样点位置不敏感。
4. **电压通道带宽只有 ≈175 Hz**：分压戴维南 9.1 kΩ + 22 Ω 串 R105 驱动 C175 100 nF → τ ≈ 0.9 ms。电流通道因为 INA 输出阻抗低，τ = 2.2 µs。**也就是说"母线电压"比"电流"慢近 400 倍** —— 任何用 `V_A` 做除法/前馈的地方都有 ~1 ms 的滞后。
5. `INA240 VS = 3V3`，REF1=GND、REF2=3V3REF → 零点 = 1.65 V，且与 ADC 基准**同一颗 REF3033**（比例式，零点误差对消）—— 好设计。但 3.3 V 供电下输出摆幅约 ±1.55 V → **实际线性区 ±19.4 A**，而 buffer 模式 `MAX_B_Current = 20 A`，已在饱和边缘。

## 2. 工作逻辑（网表 + 固件对齐后的实际时序）

### 2.1 上电

1. `A` 或 `B` 任一侧有电 → `D1/D2` 或门 → `F1` → `U1/U2` → 10.1 V（栅驱）+ 5 V → 3.3 V（MCU/INA/CAN）+ 3.3 V 基准。
2. MCU 起振后 5 路 ADC 自校准、OPAMP 跟随器使能、HRTIM 计数器先跑但**输出关闭**、CAN/UART 就绪。
3. 上电默认 `Enable_Flag = 0`、`Max_Referee_P = 20 W`、`Power_Buff_Energy = 55`，PWM 保持关断，等第一帧控制帧。
4. 1 s 内收不到帧 → `NVIC_SystemReset()`。**受控模式下无上位机时就是 ~1 s 周期反复复位**（README 已声明，属预期，但对"上位机主动禁用"场景是坑：禁用也会被复位成"待使能"）。

### 2.2 正常运行

- 上位机 100 Hz 下发 `0x30`：`Enable / Power_Buff_Energy / Max_Referee_P`（3 字节，**无 CRC**）。
- 板子 100 Hz 回 `0x31`：`State / V_cap×100 / P_ref×10 / P_chassis×10`（7 字节）。
- 主循环（自由运行，读数万 Hz）：采样 → 控制 → 写 HRTIM 比较值。
- 1 kHz：保护 + 灯语；100 Hz：回帧 + 通信看门狗计数；10 Hz：OLED（**在中断里阻塞发送**）；1 Hz：自复位判据。

### 2.3 功率流向的物理含义

控制器实际只调一个量：`Target_A_P`（**A 侧功率**，正 = 从 A 母线取电送往电容 = 充电；负 = 电容放电回灌 A 母线）。

- 底盘负载 < 允许功率 → `P_ref < Max` → `Target_A_P > 0` → 电容**充电**；
- 底盘负载 > 允许功率 → `Target_A_P < 0` → 电容**放电补差**，把 `P_ref` 压在 `Max_Referee_P` 上。

数量级：缓冲 55 J，若补 20 W 则维持 ≈2.75 s；补 80 W 只能维持 ≈0.7 s。**所以"能不能补"完全取决于电容里有多少能量**，而能量只能从"负载低于限额的间隙"里攒。

## 3. 现有控制链逐环拆解

```
P_ref 实测 ──►(+)──► Referee_P_PID (Kp=1.0, Ki=0.03/拍)  ──┐
   目标 = Max_Referee_P − PowerBuffer.Output                 │
                                                             ├─ min/max 选择 ──► Target_A_P
   Cap_Vmax_PID (Ki=0.03) 目标 25.5 ─────────────────────────┤                        │
   Cap_Vmin_PID (Ki=0.03) 目标 8.0  ─────────────────────────┘                        │
                                                                                      ▼
   P_A 实测 ──►(−)──► CAP_P_PID (Kp=1e-3, Ki=1e-4/拍, 限幅±23) ──► ΔV ──► ratio=(V_B+ΔV)/V_A
                                                                                      │
                                              查表：buck / 过渡 / boost  ──► A_Duty, B_Duty ──► HRTIM CMP3
```

`PID_Calculate` 是增量式：`Out += Kp·Δe + Ki·e`  ⇒ 等效 `Out = Kp·e + Ki·Σe`（即 PI，`Kp` 不是纯比例而是"累积后的比例"，语义容易误读）。

### 3.1 环路带宽估算

被控对象：`ΔV` → 电感电压 `0.95·ΔV` → 电流 `0.95ΔV/(Ls+R_par)`，`L=10 µH`、`R_par ≈ 8 mΩ(两串分流) + 2×6.6 mΩ(FET) + DCR ≈ 25 mΩ`
→ 直流跨导 **≈38 A/V**（24 V 下 ≈910 W/V），极点 `1/(2π·400 µs) ≈ 400 Hz`。

- 功率内环 `CAP_P_PID`：`Ki/Ts = 1e-4 × 30 kHz = 3 (V/W)/s` → 穿越频率 ≈ **300 Hz**，相位裕度 ≈40°（偏紧）。
- 功率外环 `Referee_P_PID`：Kp=1.0 W/W 叠在 300 Hz 内环上，`Ki/Ts = 900/s` → 穿越约 100–200 Hz。
  **两级带宽太接近（外环没有明显慢于内环），是典型的"两个环打架"配置**，实测容易出现低频起伏。

### 3.2 关键结论：增益是"每拍"量

所有 `Ki` 都按**采样次数**计，而采样率 = 主循环速度（几十 kHz，且随 OLED 刷新抖动）。采样率掉 10 倍，穿越频率就掉 10 倍、相位裕度同步恶化。这不是"优雅"问题，是稳定性问题。

## 4. 现有算法的实质问题（按危害排序）

### 4.1 两个电压限幅环实际不工作 ★★★

`Cap_Vmax_PID`：目标 25.5、反馈 `V_B`。**正常工况 `V_B < 25.5` ⇒ 误差恒正 ⇒ 输出积分到 +`A_P_Max` 并饱和。**

选择逻辑：

```c
if (Vmax_out < Ref_out) Target = Vmax_out;     // 只有 Vmax_out 更小才限幅
else if (Vmin_out > Ref_out) Target = Vmin_out;
else Target = Ref_out;
```

`Vmax_out` 饱和在 `+A_P_Max`，而 `Ref_out` 被限幅在 `±A_P_Max` → **永远不可能 `Vmax_out < Ref_out`** → 该环永不接管。
等 `V_B` 真的越过 25.5 V，误差转负，积分从 `+A_P_Max` 往下退，速度 `Ki·|e|`：把 360 W 退到 60 W 需要 `300/(0.03×0.5) = 20000` 拍 ≈ **0.7 s** —— 早就充爆了。

`Cap_Vmin_PID` 完全对称地失效（饱和在 `−A_P_Max`）。

**实际结果**：充电没有 25.5 V 软收敛，只能靠 27 V 硬保护关断；放电没有 8 V 软限，只能靠 6 V `Cap_Empty_Flag` 强制 30 W 预充。两处都退化成 **bang-bang**（26/27 V 来回开关、6~9 V 来回跳），母线电流呈低频方波。

> **更正（2026-10-27，依据 RM 规则口径）**：本条最初判定旧固件把能量环符号写反了，**该判定错误，予以撤回**。
>
> 错因：我把 `Power_Buff_Energy` 当成了"电容里存了多少能量"。实际它来自裁判系统，是**缓冲额度**——从电管取电超限则扣减、低于限额则回涨，归零扣血。按这个口径：
>
> ```
> dE_Buff/dt = P_Limit − P_Ref
> ```
>
> 缓冲能量低 ⇒ 说明此前取电取超了 ⇒ **应当少取电**。旧代码 `target = Max_Referee_P − PowerBuffer.Output`（`Output` 为正时做减法）方向恰好正确。
>
> 下文为原始记录，仅作为"当时的推理"保留，结论不再采用。

原始推理（错误）：

```c
PID_Calculate(&PowerBuffer_PID, 55.0f, Power_Buff_Energy);   // e>0 ⇔ 能量低
... PID_Calculate(&Referee_P_PID, Max_Referee_P - PowerBuffer.Output, Referee_P);
```

~~稳态 `P_A = (Max − Δ) − P_load`：`Δ > 0` ⇒ 取电变少 ⇒ 电容放电更多；而能量低恰好产生 `Δ>0` ⇒ 能量越低越放，正反馈。~~

**正确的设计见 `Doc/开发文档-控制软件重写.md` §3（能量模型）与 §7.4（缓冲环）**：被控对象是积分器，用 P 控即可，且天然无积分饱和。

### 4.3 没有负载前馈 ★★★

`Target_A_P` 完全由 `Referee_P` 的误差积分产生。ESC 电流阶跃 → `P_ref` 先冲高 → 外环（~150 Hz）+ 内环（~300 Hz）两级滞后才把它拉回 → **功率过冲持续几毫秒到十几毫秒**，正好被裁判功率计看到。
而 `Chassis_P = Referee_P − A_Power_P` **已经在算了，却只用于上报**。见 §5.3，用它做前馈几乎零成本。

### 4.4 保护环被 OLED 阻塞 ★★★

`HAL_TIM_PeriodElapsedCallback(htim7)`（1 kHz）里，10 Hz 分支直接调用 `OLED_Printf` + `OLED_Update()`；`OLED_Update` 是 8 页 ×（3 条命令 + 129 B 阻塞 `HAL_I2C_Master_Transmit(..., timeout=1ms)`）。

- I2C 时序 `0x4052060F` → PRESC=4/SCLH=6/SCLL=15 → SCL ≈ **1.3 MHz**，而 SSD1306 上限 400 kHz（超规，靠器件宽容工作）。
- 128 B × 9 bit / 1.3 MHz ≈ 0.9 ms/页 → **整屏 ≈7–8 ms**，全部发生在 1 kHz 中断里。
- 后果三重：① 保护 `Cap_ErrorHandle` 停摆 7–8 ms（等于保护变成 ~930 Hz 且有 8 ms 盲区）；② 主循环控制环同步停摆，等效附加相位滞后 `2π·f·7.5 ms`（40 Hz 时 ≈108°）；③ 控制周期不定 → §3.2 的增益漂移。

### 4.5 电流环缺失、B 侧电流白测 ★★

`B_Power_I / B_Power_P` 全工程**只被计算、从未使用**。而它是天然的内环反馈（还自带过流判据）。
现状把"功率"当最内环，被控对象里含 `1/R_par`（FET 的 Rds_on 随结温上升 ~40%、分流电阻 ±1%），直流增益在 25–35 mΩ 之间漂 → 环路增益同比例漂。

### 4.6 过流保护不可用 ★★

```c
// if(fabs(A_Power_I) >= 40.0f || ...) { ... }
```

不仅被注释，而且 **40 A 阈值高于传感器满量程 20.6 A**，即使打开也是死代码。硬件侧也没有任何比较器 → **软件是唯一防线，且这道防线现在是空的**。
另外 B 侧（电容组 → CN2/CN3 → FET）**没有保险丝**，只有 4 mΩ 分流和 TVS；Q9/Q10 一旦直通，电容组会毫无阻挡地灌进去。

### 4.7 CAN_RX 上的 100 nF ★★[需实测]

`C71 = 100 nF` 并在 `CAN_RX`（U11.RXD —22 Ω— PB5，另有 10 k 上拉）。
1 Mbps 位宽 1 µs；`(22 Ω + RXD 输出阻抗) × 100 nF` 的时间常数 2–7 µs，**比位宽大一个数量级** → 边沿被完全积分，PB5 只会看到"位流平均值"。按 125 kbps 反而能通。
**要么 CAN 实际跑不到 1 Mbps，要么 C71 是画错的（大概率是，和 R131/SW1 一起像是给某个按键留的 RC）。**
建议示波器直接看 PB5 眼图；若确认，摘掉 C71（或改 ≤ 470 pF）。

### 4.8 PB8 = BOOT0 用作 OLED SCL ★★[需实测]

`U22.61` 网表名就是 `PB8-BOOT0`，接 `R141 22Ω → H1(OLED SCL)`。若 OLED 模组自带 4.7–10 kΩ 上拉，复位瞬间 BOOT0 被拉高 → 进系统 Bootloader 而非用户 Flash，**表现是"上电偶发不启动/要按复位"**。建议确认模组是否有上拉；有则加 10 k 下拉或换引脚。

## 5. 更优的控制算法

### 5.1 总体思路

把"一个 PI 管一切"换成**三层级联 + 前馈 + 参考值域限幅**，并让每一层跑在**固定、与开关同步**的节拍上：

```
            ┌──────────────── 100 Hz（收帧时） ────────────────┐
  E_cap ──► │ 能量环 PI（带宽 1–2 Hz，带死区）→ P_trim (±20 W) │
            └───────────────────────┬─────────────────────────┘
                                    ▼
            ┌──────────────── 1–2 kHz ─────────────────────────┐
 P_ref(滤波)│ 功率环：P_allow = Max_Referee_P + P_trim          │
            │         P_A_ref = (P_allow − P_load)   ← 负载前馈│
            │                 + PI_p(P_allow − P_ref) ← 只修残差│
            └───────────────────────┬─────────────────────────┘
                                    ▼
            ┌──────────────── 20 kHz（固定 ISR，PWM 同步）──────┐
            │ I_B_ref = P_A_ref / V_B          ← 电压归一化     │
            │ taper : I_chg/dis_max(V_B)       ← 电压限幅       │
            │ 电流环 PI(I_B_ref − I_B) → ΔD                     │
            │ D = D_ff(V_A,V_B) ± ΔD           ← 占空比前馈     │
            └──────────────────────────────────────────────────┘
```

三层带宽拉开 10 倍以上（2 Hz / 200 Hz / 2 kHz），彻底消除 §3.1 的"两环打架"。

### 5.2 内环：平均电流环 + 占空比前馈（替代 `ΔV` 域）

**为什么**：`I_B` 已经测了但没用；用电流做内环，被控对象变成 `1/(Ls+R)`，**直流增益不再依赖 `R_par` 与工况**，且能把带宽从 300 Hz 提到 1–2 kHz。

```c
/* 20 kHz ISR */
float D_ff = V_B / V_A;                       // buck 区稳态占空比（V_B<V_A）
// or boost: D_A_ff = 0.95f, D_B_ff = 0.95f*V_A/V_B
float err  = I_B_ref - I_B_filt;
I_int += Kp_I* (err - err_last) + Ki_I*err;   // Ki_I = ki_per_sec * Ts
I_int  = clamp(I_int, -0.35f, +0.35f);        // 占空比裕量，天然限幅
float D    = clamp(D_ff + I_int, 0.05f, 0.95f);
```

- `Ki_I` 用"每秒"量纲：`Ki_I = 2π·fc·Ts` 之类，与调度频率解耦；
- 180° 交错、`CMP4` 触发采样继续保持（这两点原本就设计对了）；
- **把 `CMP1/CMP3/CMP4` 的预载打开**（`PreloadEnable = HRTIM_PRELOAD_ENABLED` + `UPDATEONREPETITION`）。现在 `PRELOAD_DISABLED` 意味着在主循环任意时刻写 `CMP3`：若写入时计数器已越过新值，本周期不会复位 → **偶发一个整周期 100% 占空的脉冲**（≈1/11 的周期有这个风险）。这是当前最容易被忽略的"硬件级"缺陷之一。

### 5.3 中环：功率环 + 负载前馈（解决 §4.3）

```c
/* 1–2 kHz */
P_ref_f  = LPF(P_ref, 150 Hz);            // 抑制 ESC 纹波，别去追瞬时值
P_load   = P_ref_f - P_A;                  // 已经是现成的 Chassis_P
P_allow  = Max_Referee_P + P_trim;

P_A_ff   = P_allow - P_load;               // ★ 负载前馈：阶跃时刻立刻给出
P_A_ref  = P_A_ff + PI_p(P_allow - P_ref_f);
P_A_ref  = clamp(P_A_ref, -A_P_Max, +A_P_Max);
```

- 前馈增益 1.0，稳态即精确（`P_ref = P_load + P_A = P_allow`），PI 只修损耗/标定残差 → **带宽可以提高，超调趋零**；
- 注意两点：① 前馈要**斜率限幅**（`|dP_A_ff/dt| < 4 kW/s`）避免把负载噪声直接打成电流阶跃；② `P_load` 依赖 `V_A`，而 `V_A` 通道只有 175 Hz（§1.2-4），所以前馈用**电流形式**更稳：`I_A_ff = P_allow/V_A − I_load`，再用 `P_A_ff = V_A·I_A_ff` 回代，或直接对 `V_A` 单独做一阶超前补偿。
- 功率环 PI 加**单边积分 + 死区**：只有 `P_ref > P_allow + 2 W` 时才积分（防"负载低于限额时积分把电容抽干"），死区内不动作。

### 5.4 外环：能量/SoC 环（修正 §4.2）

作用点改到**电容功率参考**，符号天然确定：

```c
E_now  = 0.5f * C_cap * V_B*V_B;          // 或直接用上位机给的 Power_Buff_Energy
E_ref  = 0.90f * E_max;                    // 留 10% 裕量
if (fabsf(E_now - E_ref) > 5.0f)           // ±5 J 死区
    P_trim += Ki_E * (E_ref - E_now);      // 能量低 → P_trim↑ → 多回充
P_trim  = clamp(P_trim, -20.0f, +20.0f);
```

`P_allow` 会短暂超过 `Max_Referee_P` 达 `P_trim`（最多 20 W），必须由上位机/能量账本允许；若规则不允许越限，则改成 **`P_trim ≤ 0`（只许少取不许超取）**，并在 §5.5 的低电压 taper 里优先保放电能力。

### 5.5 电压限幅：从"积分器"改成"参考值域的乘性 taper"（修正 §4.1）

限幅必须是**代数约束**，不能是"饱和的积分器"：

```c
/* 充电上限：25.5 V 前 2.5 V 内线性收敛，留 0.3 V 硬截 */
float head = (CAP_MAX_V - V_B) / TAPER_V;              // TAPER_V = 2.5
float k_chg = clamp(head, 0.0f, 1.0f);
/* 放电下限：8 V 之上 2 V 内收敛 */
float tail = (V_B - CAP_MIN_V) / TAPER_V2;             // TAPER_V2 = 2.0
float k_dis = clamp(tail, 0.0f, 1.0f);

float I_max_chg = MAX_B_Current * k_chg;
float I_max_dis = MAX_B_Current * k_dis;
I_B_ref = clamp(P_A_ref / V_B, -I_max_dis, +I_max_chg);
```

- 优点：`V_B → 25.5` 时电流连续收敛到 0，**没有 bang-bang**；能量越满越慢，天然软着陆；
- 更讲究一点用**能量口径**：`P_chg_max = (E_max − E_now)/T_refill`（`T_refill ≈ 2 s`），能量线性回充、末端自动收敛，比电压 taper 更贴规则；
- 硬保护（27 V / 32 V / 过流）保留为**独立、优先、锁存**的一层，与上述软限互不依赖。

### 5.6 采样与调度改造（修正 §4.4 / §3.2）

1. **把控制搬出主循环**：ADC1 的 DMA 由 `Length=1` 改成 `Length=16`（循环），在**半/全传输完成中断**里跑控制 → 节拍 = 340 kHz/16 = **21.25 kHz，且严格与 PWM 同步**，与 OLED/主循环彻底解耦。
2. **顺便白拿 4 bit**：16 次累加平均 → 有效分辨率 +2 bit，纹波噪声大幅下降（现在每个通道只取 1 次瞬时值）。
3. **快照一致性**：同一触发组（ADC1/2/3 = TRG1；ADC4/5 = TRG2）的值成组复制到 `volatile` 结构体再计算，避免"半新半旧"的功率尖峰。
4. **OLED 移出中断**：主循环里做状态机分页刷新（每次只刷 1 页，1/N 帧完成一屏），或干脆上 DMA；`HAL_I2C_Master_Transmit(..., timeout=1)` 的 1 ms 超时也必须放大（一页 129 B 约 0.9 ms，已经贴脸）。
5. **I2C 降到 400 kHz**（SSD1306 规范上限），顺带把中断占用降到 1/3。
6. **保护单独跑**：`Cap_ErrorHandle` 留在 1 kHz（或更高）中断，且**不调用任何阻塞函数**——灯语只置标志、实际驱动放主循环。

### 5.7 建议参数表（可直接替换 §7 的旧表）

| 环 | 频率 | 形式 | 初值 |
|---|---|---|---|
| 能量环 | 100 Hz | I + ±5 J 死区 | `Ki_E = 0.5 /s`，限幅 ±20 W |
| 功率环 | 1–2 kHz | P + I，`P_ref` 预滤波 150 Hz | `Kp = 0.8 (W/W)`，`Ki = 60 /s` |
| 电流环 | 21.25 kHz | P + I（占空比输出） | `Kp = 0.02 (D/A)`，`Ki = 1200 /s`，`ΔD ∈ [-0.35, 0.35]` |
| 电压 taper | 每拍 | 代数乘性限幅 | `TAPER_V = 2.5 V` / `TAPER_V2 = 2.0 V` |
| 保护 | 1 kHz | 锁存 + 回差 | 27 V / 32 V / `|I| > 18 A`（低于满量程！） |

> 过流阈值务必落在**传感器线性区以内**（≤19 A）；更好的做法是用 ADC 的**模拟看门狗**（AWD）直接监视 OPAMP 输出通道，AWD 中断里 `HRTIM_Output_Stop()`，响应可达几个 µs 级，比 1 kHz 软件判据快两个数量级。硬件若改版，加一路比较器接 HRTIM FAULT 输入最稳（现在 `FaultEnable = NONE`，是留着的空位）。

### 5.8 参考实现（替换 `Cap_Calulate_VB_to_VA` 的骨架）

```c
/* ---- 21.25 kHz ISR（ADC 均值完成）---- */
static float I_int;
float I_B_ref = clampf(g_P_A_ref / fmaxf(V_B, 2.0f), -g_I_dis_max, +g_I_chg_max);
float e       = I_B_ref - I_B;
I_int        += PID_KI_CUR * e;                 // 已含 Ts
I_int         = clampf(I_int, -0.35f, +0.35f);
float D       = clampf(duty_ff(V_A, V_B) + I_int, 0.05f, 0.95f);
SET_AH_Duty(f(buck...)); SET_BH_Duty(...);      // 预载写入，周期边界生效

/* ---- 1.5 kHz ISR ---- */
g_I_chg_max = MAX_B_Current * clamp01((CAP_MAX_V - V_B) / 2.5f);
g_I_dis_max = MAX_B_Current * clamp01((V_B - CAP_MIN_V) / 2.0f);
float P_allow = Max_Referee_P + g_P_trim;
float P_A_ff  = P_allow - (P_ref_f - P_A);
float P_pi    = P_ref_f > P_allow + 2.0f ? PID_KI_PWR*(P_allow - P_ref_f) : 0.0f;
g_P_A_ref     = clampf(P_A_ff + P_pi, -A_P_Max, +A_P_Max);

/* ---- 100 Hz（收帧）：能量环，此处只改 g_P_trim ---- */
```

## 6. 实施顺序（风险由低到高）

| 阶段 | 动作 | 风险 | 收益 |
|---|---|---|---|
| 0 | 摘 C71、放大 OLED I2C 超时、把 OLED 移出中断 | 低 | 恢复 CAN 1 Mbps；控制/保护不再有 8 ms 盲区 |
| 1 | 打开 CMP 预载 + 周期边界更新 | 低 | 消除偶发 100% 占空比脉冲 |
| 2 | 电压限幅改成 taper（§5.5） | 低 | 25.5 V 软收敛、不再 26/27 V 振荡 |
| 3 | 控制搬进 21.25 kHz ADC 中断 + 16 次均值 | 中 | 增益稳定、噪声下降 2 bit |
| 4 | 电流内环 + 占空比前馈（§5.2） | 中 | 带宽 300 Hz → 1.5 kHz |
| 5 | 负载前馈 + 单边积分（§5.3） | 中 | 负载阶跃不再顶破裁判功率 |
| 6 | 过流（AWD/比较器）+ B 侧保险丝 | 中/需改板 | 故障不炸管 |

每步都能单独验证：阶段 2 用直流源把 `V_B` 从 20 V 缓慢拉到 26 V，看充电电流是否在 23 V 后平滑降到 0；阶段 5 用电子负载做 0→100 W 阶跃，看 `0x31` 里的 `Referee_P` 过冲是否从十几瓦降到几瓦。
