## 1. 需求与边界

### 1.1 RM 规则口径

```
      电管(功率计) ──REF──► [超电控制板] ──CHA──► 底盘电机
                                   │
                                   B ──► 超级电容组
```

| 规则事实 | 设计影响 |
|---|---|
| 裁判系统 10 Hz 下发 **功率限制**、**缓冲区能量**(0–60 J) | `P_Limit`、`E_Buff` 以 10 Hz 刷新 |
| 取电**超过**限制 → 扣缓冲；**低于**限制 → 缓冲回涨；归零扣血 | 恒功率取电 ⇒ `dE_Buff/dt=0` ⇒ 物理上排除扣血 |
| 从电管取电的功率/电流**不额外限制** | 允许 `P_Tgt > P_Limit`（本版 `P_OVER = 5 W`，见 §8.4） |
| **电容组充放电流 ≤ 15 A**（保护官方功率计） | `I_B` 硬限 15 A，充放对称 |
| 期望电容工作区间 **8–25.5 V**，调节点 25.5 V | 低端 8 V 是人为限制（放到 0 V 电流过大） |
| **> 26 V 执行超压保护**；26 V 是期望工作上限 | 正常充电稳在 25.5 V；**动能回收不限幅**，放宽到 25.9 V（留 0.1 V 裕量） |
| **26.5 V 是电容物理极限**；电容板自带 26.5 V 以上的 1 A 泄放 | 超 26.5 V 时**充电电流必须 ≤1 A**（否则电容板泄放跟不上）；同时超电板应**主动泄放 1 A（反冲电池/底盘）**提速降压；回落到 25.5 V 自动解锁 |

### 1.2 必须不变（"上层应用一样"）

| 项 | 约束 |
|---|---|
| CAN `0x30` | 标准帧 3 字节：`Enable_Flag` / `Power_Buff_Energy` / `Max_Referee_P`（逐字节一致） |
| CAN `0x31` | 标准帧 **8 字节 DLC**：`State` / `V_Cap×100` / `P_Ref×10` / `P_Cha×10`（`State` 仍 0/1） |
| UART | **1 Mbaud** 8N1，8 字节，`Data[6]=0x55, Data[7]=0xAA`，前 3 字节同 CAN |
| 频率 | `0x31` 100 Hz；通信看门狗 500 ms |
| OLED | 同套字段（可加页，不可删）；I2C1 0x78 |
| 灯语 | 绿闪=未使能 / 蓝闪=底盘离线 / 红常亮=过压 / RGB 同步 1 Hz=正常 |
| 标定 | 仍按 `UID w0` 查表加载 V/I 校准系数 |

### 1.3 允许改变（已确认）

1. 删掉"禁用 1 s 后 `NVIC_SystemReset()`"（Q1 已关闭）→ 改 IWDG。
2. 过流保护真实生效（阈值落在量程内）。
3. OLED 移出 1 kHz 中断。
4. **删除 `IF_USED_AS_BAT_BUFFER` 电池缓冲模式**——只保留受控模式。

## 2. 命名规范

### 2.1 两类命名，各管一层

| 层 | 命名 | 理由 |
|---|---|---|
| **功率端口** | `Ref` / `Cha` / `Cap` | 对应 REF / CHA / B 三个连接器，物理位置清晰 |
| **BuckBoost 本体** | `A` / `B` | A 侧 = 电管/底盘侧桥，B 侧 = 电容侧桥；占空比、电流、调制都用 A/B |

### 2.2 信号表

| 新名 | 含义 | 采样点 | 旧代码名 |
|---|---|---|---|
| **`V_A`** | A 侧母线电压 | PA3，R23/R24 11:1 | `CapData.A_Power_V` |
| **`V_B`** | B 侧母线（电容侧）电压 | PB14，R26/R27 11:1 | `CapData.B_Power_V` |
| **`I_Ref`** | 电管输出电流 | R77 4 mΩ + U30 | `CapData.Referee_I` |
| **`I_A`** | 流入 BuckBoost A 侧的电流 | R6 4 mΩ + U29 | `CapData.A_Power_I` |
| **`I_Cha`** | 底盘电流 = `I_Ref − I_A` | 差分得到 | `Chassis_P` 的分子 |
| **`I_B`** | 电容组电流 | R79 4 mΩ + U31 | `CapData.B_Power_I` |
| `P_Ref` | 电管功率（**被控量**） | `V_A·I_Ref` | `CapData.Referee_P` |
| `P_A` | BuckBoost A 侧功率 | `V_A·I_A` | `CapData.A_Power_P` |
| `P_Cha` | 底盘功率 | `V_A·I_Cha` | `CapData.Chassis_P` |
| `P_B` | 电容功率（正=充） | `V_B·I_B` | `CapData.B_Power_P` |
| **`D_A`** | A 桥占空比 | PA8/PA9 (HRTIM A) | `CapControl.A_Duty` |
| **`D_B`** | B 桥占空比 | PA10/PA11 (HRTIM B) | `CapControl.B_Duty` |
| `r` | 变比 `V_B/V_A` | — | `VB_to_VA_Set`（旧版是"含 ΔV 的指令"，新版是纯电压比） |
| `P_Limit` / `E_Buff` / `P_Tgt` | 限额 / 缓冲能量 / 取电目标 | 协议 / 计算 | `Max_Referee_P` / `Power_Buff_Energy` / 旧版无 |

**关键关系**（功率路径正是你描述的那条）：

```
电管 ──I_Ref──► 节点 ──I_Cha──► 底盘电机
                 └────I_A────► BuckBoost ──I_B──► 电容组

I_Ref = I_Cha + I_A      P_Ref = P_Cha + P_A
```

因为 CHA 抽头正好在 R77 与 R6 之间，`I_Cha` 由**两个同规格 4 mΩ + 同增益 INA240 差分**得出，零点与增益误差大部分对消——比旧版 `P_Ref − P_A` 相减更准。

## 3. 能量模型

### 3.1 两条守恒

```
dE_Buff/dt = P_Limit − P_Ref        ← 裁判记账（虚拟额度）
dE_Cap /dt = P_Ref   − P_Cha        ← 物理电容
────────────────────────────────────
d(E_Buff + E_Cap)/dt = P_Limit − P_Cha    ← 总量只由底盘决定
```

**三条推论**

1. **恒功率取电 = 扣血的物理免疫。** `P_Ref = P_Limit` ⇒ `dE_Buff/dt = 0`，缓冲永不消耗 ⇒ 不可能归零。
2. **模块只能决定"存哪儿"。** `E_Buff` 与 `E_Cap` 是两个连通水桶，总水量由底盘决定。目标 = 缓冲不归零（不扣血）+ 电容尽量满（有削峰能力）。
3. **底盘永远直接从 REF 取电**，`P_Ref = P_Cha + P_A`，`P_A` 是唯一可控项。负载一重先放电容；电容放空（8 V taper）后 `P_A` 被夹住，`P_Ref` 才被动升上去吃缓冲 ⇒ **电容 SoC 才是真瓶颈**。

### 3.2 为什么缓冲目标取 55 J（不是 60）

`E_Buff` 是**裁判的**记账，我们的 `P_Ref` 与之存在 ±1~2% 的增益/零点误差。缓冲环用 P 控制时（被控对象是积分器，P 控即无稳态差）：

| δ = 我们测到的 `P_Ref` − 裁判真值 | 真实取电 | 缓冲停车点 |
|---|---|---|
| −2 W | **80.0 W = P_Limit** | 53 J |
| 0 | **80.0 W** | 55 J |
| +2 W | **80.0 W** | 57 J |

> **真实取电恒为 `P_Limit`，与 δ 无关** —— 这正是"把功率用满"。代价是缓冲停车点偏移 `δ/KP_E`；
> 取 `E_TGT = 55 J` + `KP_E = 1.0` 时停车点落在 **53~57 J**，距 60 J 天花板还有 3 J 余量。
> 仿真验证见 §11 的 L 项。

## 5. 调制器：让 `V_L = u·V_A` 恒成立

### 5.1 定义

`r = V_B/V_A`，控制量 `u` = 归一化占空比增量：

```
buck  :  D_B = c            boost :  D_A = c
         D_A = c·r + u              D_B = (c − u)/r
```

代入 `V_L = D_A·V_A − D_B·V_B`、`V_B = r·V_A`：两式**都精确得到 `V_L = u·V_A`**。
因为是恒等式，**任意凸组合也成立** ⇒ 用平权混合实现无扰切换：

```c
r = V_B / V_A;
c = DMAX - DH*max(0, 1 - |r-1|/RB);        // 过渡区下压共同占空比，制造双向裕量
w = clamp((r - (1-BLEND/2))/BLEND, 0, 1);  // r<0.95→0, r>1.05→1
D_A = (1-w)*(c*r + u) + w*c;
D_B = (1-w)*c         + w*(c-u)/r;
```

### 5.2 为什么 `c(r)` 要在 `r=1` 处下压

`DMAX=0.95` 时若 `D_B` 顶在 0.95，充电方向剩余裕量为 0（物理上 `r_max = D_A/D_B = 1`）。
所以必须把 `r≈1` 处的**共同占空比**压到 `c(1) = DMAX − DH = 0.85`，留出 `±0.10` 对称裕量。代价：off-time 5%→15%，纹波略增（仍约 1 A）。

### 5.3 性质（已验证）

| 性质 | 结果 |
|---|---|
| **精确** | `V_B ∈ [8,25.5]`、`u ∈ ±0.04` 全域，未钳位点最大偏差 **0.0000 mV** |
| **恒增益** | `u → V_L` 增益恒为 `V_A`，与 `r` 无关 ⇒ 电流环一组参数覆盖全工况 |
| **连续** | `c(r)`、`w(r)` 连续 ⇒ `V_B` 在 `V_A` 附近抖动不产生电流毛刺 |
| **裕量充裕** | 稳态 `u_ss = I·R_bridge/V_A`，14 A 时仅 **0.011** |

| V_B | r | D_A | D_B | 区间 |
|---|---|---|---|---|
| 8.0 | 0.333 | 0.3167 | 0.9500 | buck |
| 12.0 | 0.500 | 0.4750 | 0.9500 | buck |
| 18.0 | 0.750 | 0.7125 | 0.9500 | buck |
| 22.0 | 0.917 | 0.8708 | 0.9500 | 过渡 |

## 6. 死区时间计算（本版重算）

### 6.0 ⚠ HAL 版本陷阱（2026-10-27 实测）

ST 在 **HAL 1.2.6 → 1.2.7** 之间把 `HRTIM_TIMDEADTIME_PRESCALERRATIO_*` 的**宏值**换了一遍
（`stm32g4xx_hal_hrtim.h` 里那段 "customer reported ... were swapped" 的注释）：

| 宏名 | 1.2.6 的值 | 1.2.7 的值 |
|---|---|---|
| `..._MUL8` | 0x6 | **0x0** |
| `..._DIV8` | 0x0 | **0x6** |

也就是说**同一个宏名在两版 HAL 下编程出不同的 DTPRSC，实际死区差 64 倍**。旧固件用的就是这个
`DIV8`，所以它当年到底是多少死区，取决于当时编译用的 HAL 版本——不能想当然。

**死区完全由 `.ioc` 配置**（软件层不做任何覆盖，便于在 CubeMX 里直接看到和调整）：

```
HRTIM1.RisingValue-Output_TA1TA2  = 10        # 10 个计数
HRTIM1.FallingValue-Output_TA1TA2 = 10
HRTIM1.PrescalerDead-Output_TA1TA2 = HRTIM_TIMDEADTIME_PRESCALERRATIO_DIV8
（TB1TB2 同）
```

CubeMX 生成到 `hrtim.c` 的 `pDeadTimeCfg`。**物理死区必须在台架上示波器确认**
（这是本设计唯一无法离线定论的参数，原因就是上面那个 HAL 宏值变更）：

| 实测死区 | 判定 | 处理 |
|---|---|---|
| ≈ 14.7 ns | 每计数 1.472 ns，符合设计 | 保持 `.ioc` 现值 |
| ≈ 0（几乎无死区） | 每计数只有 23 ps | **在 CubeMX 里**把 `PrescalerDead` 改成 `MUL8`（或把计数值加大到能测出的档位），重新生成 |

### 6.1 时基

`HRTIM_TIMDEADTIME_PRESCALERRATIO_DIV8` ⇒ `f_DTG = f_HRTIM/8 = 5.44 GHz/8 = 680 MHz`
⇒ **1 计数 = 1.472 ns**。

| 设置 | 计数 | 死区 | 占周期(2.94 µs) |
|---|---|---|---|
| 旧固件 | 1 | **1.47 ns** | 0.05% |
| 上一版（过量） | 20 | 29.4 ns | 1.00% |
| **本版建议** | **10** | **14.7 ns** | 0.50% |

### 6.2 需要多少

导通前必须确保另一管**电流已关断**。BSC066N06NS（60 V OptiMOS，TDSON-8）+ 非对称栅驱：

| 量 | 符号 | 值 | 说明 |
|---|---|---|---|
| 关断传输延迟 | `td(off)` | ≈17 ns | 手册 typ @10 V |
| 米勒平台关断时间 | `t_f` | ≈2 ns | 经 D8 泄放：`I_g=(4.2−0.7)/1.5≈2.3 A`，`t=Qgd/I_g=4.5n/2.3` |
| 开通传输延迟 | `td(on)` | ≈9 ns | 手册 typ |
| 开通米勒时间 | `t_r` | ≈4.5 ns | 经 R3 3.3 Ω：`I_g=(10−4.2)/5.8≈1.0 A` |

```
t_dead,min = [td(off) + t_f] − td(on) = (17 + 2) − 9 ≈ 10 ns
t_dead,设计 = 10 ns × 1.5（覆盖驱动延迟匹配与温度漂移）≈ 15 ns
           → 取 10 计数 = 14.7 ns
```

> 旧固件的 1.47 ns 之所以"用着还行"：非对称驱动本身提供了 ≈10 ns 的**典型**死区，刚好压线。
> 但它依赖器件一致性，不是设计保证——温度、批次、驱动延迟匹配任何一项偏差都可能直通。

### 6.3 代价有多少（回答"会不会增加损耗"）

| 死区 | 体二极管导通损耗 | 占空比损失 |
|---|---|---|
| 1.47 ns | 0.012 W | 0.05% |
| **14.7 ns** | **0.119 W** | **0.50%** |
| 29.4 ns | 0.238 W | 1.00% |

`P = V_F·I·t_dead·f_sw·2`（取 `V_F=0.85 V`、`I=14 A`）。

**结论**：从 29.4 ns 降到 14.7 ns 只省 **0.12 W（0.02%）**——损耗不是主要矛盾，加长的真正代价是**占空比范围与死区畸变**。但从 1.47 ns 加到 14.7 ns 换来"设计保证"，代价仅 0.1 W + 0.5% 占空比，非常划算。

> 后续用示波器测 Vgs/Vds 交叉点复核：若某管关断明显慢于计算值，再上调到 12~14 计数。

## 7. 采样

### 7.1 量程（决定保护阈值）

INA240A1（×20）+ 4 mΩ 分流 + `VS=3V3`、`REF2=3V3REF`：

```
灵敏度        0.004 Ω × 20 V/V = 80 mV/A  → 12.5 A/V
零点          1.65 V（与 ADC 基准同一颗 REF3033，比例式）
ADC 满量程    3.3 V  →  3.3/4096 = 0.806 mV/LSB  →  ±20.6 A
```

**关键限制：INA240 的正向摆幅**。输出上限 ≈ `VS − 0.2 V = 3.1 V`（worst case 3.0 V），
所以**正向只能测到 `(3.1−1.65)/0.08 = 18.1 A`**（worst case 16.9 A），而负向因零点在 1.65 V
可到 −20 A。也就是说 15 A 运行点已经用掉正向量程的 83%。

| 结论 | 值 |
|---|---|
| 可读正向上限 | **≈18.1 A**（typ）/ 16.9 A（worst） |
| 保护动作点 | **16.5 A**（=2.97 V，离电源轨 330 mV；对 15 A 运行限留 10%） |
| 后备判据 | ADC 码 ≥ 3700（≈16.9 A，即接近摆幅上限）持续 > 2 ms |
| 电容电流设计上限 | 15 A（规则），距保护点 10% 余量 |

> **为什么不能设到 20 A**：20 A 需要输出 3.25 V，已经超过 `VS−0.2 V` 的摆幅——放大器会先削顶，
> ADC 读到的是削顶值而不是真实电流，设多少都不会可靠动作。所以动作点必须在摆幅以内；
> 真到 20 A 以上时输出被削在 ~3.0–3.1 V，码值仍高于 3700 的后备判据，**依然会跳闸**，只是无法量化。
>
> **这也意味着 15 A 规则限已经接近这颗传感器的量程边界**。若以后要做 20 A 级设计，
> 换 2 mΩ 分流（或 INA240A2 ×50 配 1 mΩ）才有余量。

### 7.2 采样调度

| 项 | 方案 | 依据 |
|---|---|---|
| 触发点 | HRTIM CMP4，**始终取导通窗口中点** = `D·8000`（下限 96 计数） | 电流通道测的是斩波后的支路电流，关断窗口里≈0；若 D 跨 0.5 时切到关断窗口，采样值会在两个量级间跳（实测 `I_A` 0.2~2A 乱跳） |
| DMA | 每通道长度 **16**，循环 | — |
| 控制节拍 | ADC1 DMA 传输完成中断 = 340k/16 = **21.25 kHz**（47.06 µs），与 PWM 同步 | 摆脱旧版主循环抖动 |
| 均值 | 16 点块平均 | 等效 +4 bit，噪声 ↓4 倍，延时 23.5 µs |
| 一致性 | 一次拷贝 5×16 到快照区 | 避免"半新半旧"的功率尖峰 |
| 换算 | `V = raw·(3.3/4096·11)·kV`；`I = (raw·3.3/4096 − 1.65)·12.5 + kI` | 沿用旧 UID 标定表 |

### 7.3 电感电流重构

电荷平衡 `I_A = D_A·I_L`、`I_B = D_B·I_L`：

```c
I_L = 0.5f*(I_A/D_A + I_B/D_B);   // 双路平均，模式无关，可互为冗余
```

1 LSB = 64.5 mA，16 点均值后 ≈16 mA；`I_L` 峰值 17.2 A（=15 A/0.8735）落在 `I_L_MAX = 18 A` 内。

## 8. 三层控制器与参数推导

### 8.1 延时预算 → 电流环带宽

```
Ts     = 16/340k            = 47.06 µs
T_avg  = (16/2)/340k        = 23.5 µs
T_zoh  = Ts                 = 47.06 µs
Td     = 70.6 µs
延时在 fc 处相位 = 360°·fc·Td
```

要求延时相位 ≤ 35°（保证 PM ≥ 60°）⇒ `fc ≤ 35/(360·70.6µ) = 1377 Hz`。
**取 fc = 600 Hz（原设计 1200 Hz，实测振荡后砍半留余量）→ 实际穿越仍约 1.2 kHz，sim PM 62.1°。**

> 为什么砍半：示波器量 RC 滤波后的 `REF_I`，发现 1.65 V → 1.874 V、周期 **1 ms** 的极限振荡
> （≈±2 A）。`Smp.I_L` 是“固定相位采样 + 除占空比”重构的，有效增益随 D 变化，
> 实际环路增益比模型高，所以设计穿越必须往回收。

### 8.2 电流环（21.25 kHz）

对象（经 `V_NOM/V_A` 归一化）：`I_L/u = V_NOM/(L·s + R_bridge) = 24/(10µ·s + 0.0182)`

```
Kp = 2π·fc·L/V_NOM = 2π·600·10e-6/24 = 1.571e-3    [u/A]
fz = fc/5 = 240 Hz
Ki = Kp·2π·fz = 1.571e-3·754 = 1.184                [u/(A·s)]
U_LIM = 0.08  → V_L 上限 1.92 V → 电流斜率 192 A/ms
```

**必须写成增量式**（仿真踩坑，见 §11.3）：

```c
du = Kp*(e - e_last) + Ki*e*Ts;      // 等价 Kp*e + Ki*∫e
u  = clamp(u + du, -U_LIM, +U_LIM);  // 限幅作用在状态上 ⇒ 自带抗饱和
e_last = e;
```

### 8.3 功率环（21.25 kHz 前馈 + 5 Hz 修正）

```c
P_A_ref = (P_Tgt - P_Cha_f) + trim;
// 电管接电池，允许轻微倒灌；只限幅度。倒灌判据是总功率：
//   P_Ref = P_Cha + P_A < 0  ⇔  P_A < −P_Cha   （电容给底盘放电不算倒灌）
// 限幅必须用瞬时 P_Cha —— 用滤波值会因 80 µs 滞后在卸载瞬间放过倒灌。
if (P_A_ref < -(P_Cha - P_REV_MAX)) P_A_ref = -(P_Cha - P_REV_MAX);
if (soft_ok) { trim += 2π*5*(P_Tgt - P_Ref_f)*Ts;  trim = clamp(trim, ±15 W); }
```

- `P_Cha_f`：**2 kHz** 一阶低通（τ=80 µs）。太高放进 ESC 纹波，太低前馈滞后；
- `P_Ref_f`：150 Hz，只给修正通道；
- **软启动期间禁止积分**。仿真中上电时 `P_Ref_f` 从 0 起跳，`trim` 被冲到几十瓦，把预充电流顶到 12 A（超 8 A 设定）——必须门控。

**倒灌幅度的真实情况**（仿真 K4，400 W 突卸到 20 W）：

| 量 | 值 | 说明 |
|---|---|---|
| 指令侧稳态限幅 | −40 W | `P_REV_MAX`，挡住故障/积分漂移导致的反向吸取 |
| 实际峰值 | **−286 W** | 电感电流从 −13 A 拉回 0 需要 ~100 µs，受 `V_L/L` 物理限制，限幅管不到 |
| 持续时间 / 能量 | **0.24 ms / 41 mJ** | 相当于给电池回充 41 mJ，相对 60 J 缓冲 = 0.07% |

> 若将来觉得这个尖峰不可接受，两条路：①把 `CUR_FC` 提到 1.8 kHz（需把 ADC 均值降到 8 点以缩短延时预算）；
> ②把 `P_Cha` 滤波提到 5 kHz。当前 41 mJ 量级不值得为它牺牲相位裕度。

### 8.4 缓冲环（166 Hz）

被控对象是积分器，**P 控即无稳态差，且无积分器 ⇒ 无积分饱和**：

```c
P_Tgt = P_Limit - KP_E*(E_TGT - E_Buff);   // 缓冲低 → 少取电
if (E_Buff < E_CRIT) P_Tgt = 0;            // 保底优先回充
P_Tgt = clamp(P_Tgt, 0, P_Limit + P_OVER); // P_OVER=5 W ⇒ 允许小幅超限以"取满"
```

`KP_E = 1.0 W/J`（τ=1 s，PM 90°）；`E_TGT = 55 J`；`E_CRIT = 10 J`；`E_Buff` 加 0.5 Hz 低通抹掉 1 J 量化台阶。

**`P_OVER = 5 W` 的作用**（§3.2 已论证）：补偿 ±1~2% 的测量偏差，使**真实取电等于 `P_Limit`**；代价是缓冲停车点偏移 `δ/KP_E`（实测 53~57 J）。

### 8.5 电容电压管理（含动能回收）

```
  V_B  | 0 ── 8 V ──────────── 25.5 V ── 25.9 ── 26.0 V ── 26.5 V ──►
       | 禁放   正常充放        正常充电  回冲上限 超压保护   物理极限
       | (预充) (taper)        收敛到 0  (不限幅) (1A 泄放)  (锁存+泄放)
       |                                    [ov]        [hw_ov]
```

```c
/* ① 充电限幅：正常 25.5 收敛；检测到动能回收则放宽到 25.9（不限制反冲） */
if      (P_Cha_f < -2.0f) regen = 1;      // ±2 W 回差，防抖动
else if (P_Cha_f > +2.0f) regen = 0;

k_norm  = clamp((25.5f - V_B)/1.5f, 0, 1);   // 正常充电
k_regen = clamp((25.9f - V_B)/0.4f, 0, 1);   // 动能回收（25.5→25.9 收敛）
k_dis   = clamp((V_B - 8.0f)/1.5f, 0, 1);

I_B_ref = P_A_ref / V_B;
I_B_lim = I_B_MAX * (I_B_ref > 0 ? (regen ? k_regen : k_norm) : k_dis);

/* ② 超压保护：26.0 触发 / 25.8 释放 */
if      (V_B >= 26.0f) ov = 1;
else if (V_B <  25.8f) ov = 0;

/* ③ 物理极限：26.5 锁存，回落到 25.5 自动解锁 */
if      (V_B >= 26.5f) hw_ov = 1;
else if (V_B <= 25.5f) hw_ov = 0;

/* ④ 主动泄放：ov 与 hw_ov 共同驱动（hw_ov 必须一路灌放到 25.5 才停） */
if (ov || hw_ov) { I_B_lim = I_DUMP; I_B_ref = -I_DUMP; }   // 1 A 向电管/底盘反冲

I_B_ref = clamp(I_B_ref, -I_B_lim, +I_B_lim);

/* ⑤ 深放电恒流预充 */
if (V_B < 8.0f) I_B_ref = min(I_B_ref, I_PRE);

I_L_ref = clamp(I_B_ref / D_B, -I_L_MAX, +I_L_MAX);
```

**关键设计点**

1. **动能回收不限幅**：只要 `P_Cha_f < −2 W` 就认定在回收动能，充电 taper 从 25.5 放宽到 **25.9 V**（保留 0.1 V 到 26.0 超压阈值，否则会长期贴在阈值上）。仿真：150 W 持续回馈，电容以 7.7 A 满功率吸收，`V_B` 停在 25.900 V，**OVP 触发 0 次**。
2. **泄放必须允许反冲电管**：正常运行时禁止把功率倒灌电管（`P_A_ref ≥ −P_Cha`）；但泄放时**例外**——1 A 反冲总比电容过压安全。
3. **`hw_ov` 不能靠 `ov` 顺带释放**：26.0 的 `ov` 在 25.8 就放开了，若 26.5 的锁存也跟着放开，电压会卡在 25.8 永远到不了 25.5 解锁点。所以泄放由 `ov || hw_ov` 共同驱动。
4. **26.5 V 以上充电电流必须 ≤1 A**：这是**电容板的约束**（它自带的 1 A 泄放要跟得上），不是我们的泄放上限。本设计在该区间充电指令恒为 0（taper 早已收敛），并主动泄放 1 A 加速降压。

| 参数 | 值 | 依据 |
|---|---|---|
| `I_B_MAX` | 15 A | RM 规则，充放对称 |
| `V_CHG_MAX` / taper | 25.5 V / 1.5 V | 正常充电调节点；1.5 V 收敛带 ≈150 ms 软着陆 |
| `V_CHG_REGEN` / taper | **25.9 V / 0.4 V** | 动能回收放宽点，留 0.1 V 给 26.0 阈值 |
| `V_DIS_MIN` / taper | 8.0 V / 1.5 V | 人为低端限制 |
| `V_OV_TRIP` / 回差 | 26.0 V / 0.2 V | 超压保护；0.2 V 回差经仿真验证无抖动 |
| `V_HW_MAX` / 解锁 | 26.5 V / **25.5 V** | 电容物理极限；泄放到 25.5 V 自动解锁 |
| `I_DUMP` | 1.0 A | 主动泄放（向电管/底盘反冲） |
| `I_PRE` | 8 A | 深放电预充，留 7 A 余量 |
| `I_L_MAX` | 18 A | `15/0.8735 = 17.2 A` + 0.8 A 余量 |

> **15 A 不是瓶颈**：`P_A = P_Tgt − P_Cha ≤ P_Tgt ≈ 85 W`，正常充放电流最多 85/25.5 = 3.3 A。
> 15 A 只在**预充**和**动能回收**这两个路径上才可能触及（回馈 150 W 时 5.8 A，回馈 380 W 才打满）。

### 8.6 保护汇总

| 故障 | 判据 | 动作 | 恢复 |
|---|---|---|---|
| 底盘离线 | `V_A < 18.0 V` | 关 PWM | `V_A > 19.0 V`（电池没电会掉到 19.2 V，故留 1.2 V 余量） |
| 母线过压 | `V_A > 32 V` | 关 PWM + 锁存 | `< 31 V` |
| 电容超压 | `V_B ≥ 26.0 V` | 禁充 + 1 A 主动泄放 | `< 25.8 V` 自动 |
| 电容物理极限 | `V_B ≥ 26.5 V` | 锁存 + 继续 1 A 泄放 | **泄放到 25.5 V 自动解锁** |
| 过流限流 | `max(|I_A|,|I_B|,|I_L|) ≥ I_LIM_SOFT`(15 A) | **只压制占空比**（电流环每拍回退 `U_LIM_BACK`） | `< I_LIM_RELEASE`(14 A) 自动 |
| 过流跳闸 | `I_Ref`/`I_A`/`I_B`/`I_L` ≥ 16.5 A 持续 `OC_TRIP_TICKS`(4 拍≈188 µs)，或 ADC 码 ≥3700（≈16.9 A）持续 2 ms | 关 PWM + 锁存 | 需 `Enable` 重上升沿 |
| 控制节拍丢失 | 1 kHz 任务连续 5 ms 未见控制中断（ADC/DMA 停摆） | 强制关 PWM | **活故障：节拍恢复即自清** |
| ~~传感器失效~~ | **整条判据已删除**（实机上持续误跳，见 §15.5 F16）；`FLT_SENSOR` 位保留但不再置位 | — | — |
| 通信丢失 | 500 ms 无合法帧 | 关 PWM 进 IDLE | 自动 |

同故障 10 s 内 3 次 ⇒ 永久锁存（`hw_ov` 除外，它按电压自动解锁）。
**L0 已从 ADC 模拟看门狗改为 21.25 kHz 软件限流**：AWD 需要在"无转换进行中"才能写入，
时机稍错就静默失效（实测回读 `AWD1EN=0`），且阀值不能带回差；软件限流把阀值全部收回
`params.h`，47 µs 发现越限并压制，持续越限才跳闸。

### 11.1 两条物理极限（需提前接受）

1. **400 W 阶跃削不干净**：15 A 上限在 19 V 仅 285 W，缺口只能由电管直供（输入升到约 127 W）。
2. **电容充满后输入功率必然回落**：`V_B→25.5 V` 时 taper 电流收到 0，输入降到 `P_Cha`。满了就吸收不了能量，属预期。

### 11.2 判据说明

瞬时 `P_Ref` 在负载阶跃边沿有 −59 W / +218 W 的**百微秒级尖峰**（被 500 µF 母线电容吸收），积分能量误差仅 +361 mJ。裁判按能量记账，故以积分误差为判据；按峰值判会误伤。

### 11.3 仿真过程中改掉的 4 个坑

1. **电流环 PI 必须增量式**。写成 `u += Kp*e`（P 项也累加）＝双积分，实测超调 **+80%**。
2. **修正积分要门控**。上电时 `P_Ref_f` 从 0 起跳，`trim` 冲到几十瓦 → 预充电流 **12 A**（超 8 A 设定）。
3. **禁止反灌电管**。负载突降时电容仍在放电，会有百微秒级负电流倒灌（真实电源不能吸收）→ 加 `P_A_ref ≥ −P_Cha`。
4. **超压阈值要回差**。26.0 V 单阈值会让泄放/充电在阈值上抖动 → 加 0.2 V 回差（K2 验证末段稳定）。

`CFG_DEBUG_UART = 1`（`params.h`），串口 **1 Mbaud** 每 100 ms 输出一帧 **VOFA+ JustFloat**

```
CH0 P_Tgt | CH1 P_Ref_Avg | CH2 P_Ref | CH3 P_Cha_Avg | CH4 I_L_Avg | CH5 V_B
```

`printf` 重定向（`comm_uart.c`）保留为行缓冲 + DMA，但与 JustFloat 共用 TX DMA，
二者不可同时使用。

1. 串口打开，`V_A`/`V_B` 与万用表比对，误差应 < 1%；
2. 钳表卡 R77 量 `I_Ref`，与打印值比对；
3. 静置时 `I_A/I_B/I_Ref` 零点应接近 0（标定表命中时 < 50 mA）；未命中 UID 的板子会走默认 1.0/0 系数，误差约 ±1.2%；
4. `I_Cha` 必须等于 `I_Ref − I_A`；
5. `I_L` 应与 `I_B/D_B`、`I_A/D_A` 基本一致（差 > 20% 说明某一路电流采样有问题）。
